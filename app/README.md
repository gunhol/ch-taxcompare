# CH Tax Compare app

React, TypeScript, and Vite application. Project overview, data provenance, deployment, and methodology are documented in the [repository README](../README.md). Contributor rules are in [AGENTS.md](../AGENTS.md).

```sh
npm ci
npm run dev
npm run lint
npm test
npm run build
```

Runtime data is bundled in `public/data/`. The production build is written to `dist/` and deployed by the root GitHub Pages workflow.
